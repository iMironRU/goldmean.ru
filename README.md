## Состояние

Собран **каркас и главная страница во всех трёх вариантах** — пункты 1–2
рекомендуемой последовательности из §13 хендоффа. Остальные 13 маршрутов
существуют как заглушки: меню и переходы на показе работают по-настоящему,
и на каждой странице написано, что на ней будет.

| Готово | Маршрут | Что там |
|---|---|---|
| ✅ | `/` | Главная, варианты `a` / `b` / `c` + блок доверия + «Почему в салоне» |
| 🔸 | `/watches` | Заглушка · каталог часов |
| 🔸 | `/jewelry` | Заглушка · украшения |
| 🔸 | `/diamonds` | Заглушка · о бриллиантах |
| 🔸 | `/master` | Заглушка · часовой мастер |
| 🔸 | `/services` | Заглушка · услуги |
| 🔸 | `/why-offline` | Заглушка · почему офлайн |
| 🔸 | `/about` | Заглушка · о магазине |
| 🔸 | `/contacts` | Заглушка · контакты и форма записи |
| 🔸 | `/gift` | Заглушка · подарочный сертификат |

Маршруты марок и карточек (`/watches/:brand`, `/watches/:brand/:ref`,
`/jewelry/:brand`, `/jewelry/:id`) появятся вместе с каталогом.

## Три варианта главной

Главная собрана во всех трёх вариантах сразу, переключение — без правки кода:

| Адрес | Вариант | Суть |
|---|---|---|
| `/?home=a` | Развилка | Два полноэкранных фото-блока «Часы» / «Украшения» |
| `/?home=b` | Редакционный | Крупный заголовок + CTA, ниже две карточки 4:5 |
| `/?home=c` | Витрина | Тёмный блок-манифест, ниже две полосы 3:2 с нумерацией |

Вариант по умолчанию — `variantDefault` в [`content/home.json`](content/home.json).
Всё, что ниже первого экрана, общее для трёх вариантов и не дублируется.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка статики:

```bash
npm run build    # -> out/
```

## Как обновить контент

Весь текст сайта — в [`content/`](content), правится без пересборки логики:

| Файл | Что внутри |
|---|---|
| `site.json` | Адрес, режим работы, телефон, соцсети, пункты меню |
| `home.json` | Тексты трёх вариантов главной, блок доверия, «Почему в салоне» |
| `routes.json` | Заголовки и описания страниц-заглушек |

Каталоги часов и украшений лягут туда же отдельными json, когда заказчик
даст прайс.

## Структура

```
goldmean.ru/
├── InBox/          ← исходные архивы от заказчика, как пришли
├── design-ref/     ← хендофф дизайна: README, токены, кликабельный прототип
├── content/        ← контент сайта в json
├── src/
│   ├── app/        ← маршруты (App Router)
│   ├── components/ ← шапка, подвал, sticky-CTA, блоки главной
│   ├── lib/        ← загрузка контента, basePath, активный пункт меню
│   └── styles/     ← tokens.css, копия из design-ref
└── AGENTS.md       ← правила проекта: читать перед правками
```

## Стек

Next.js 16 (App Router, статический экспорт), React 19, Tailwind 4.
Дизайн-токены — из `design-ref/tokens.css`, проброшены в Tailwind через
`@theme inline`. Сборка отдаёт обычную статику в `out/`: её можно положить
на GitHub Pages, залить по FTP на хостинг или отдать архивом.

## Что нужно от заказчика

Полный список — §12 хендоффа. Коротко:

1. Фотографии — сейчас везде плейсхолдеры с описанием нужного кадра.
2. Логотипы 13 часовых марок и 6 ювелирных производителей + права на них.
3. Прайс на украшения либо решение показывать «цена в салоне».
4. Актуальный Instagram и дисклеймер про Meta в подвал.
5. Канал приёма заявок: почта, Telegram-бот или CRM.
6. Срок действия подарочного сертификата.
