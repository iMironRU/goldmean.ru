## Состояние

Собраны **каркас, главная, оба каталога с карточками товара и подарочный
сертификат** — пункты 1–4 и 6 рекомендуемой последовательности из §13
хендоффа. Остальные маршруты существуют как заглушки: меню и переходы на
показе работают по-настоящему, и на каждой странице написано, что на ней будет.

### Оплата сертификата не подключена

Сайт статический, сервера нет: эквайринг подключается на этапе интеграции
(§9), канал приёма заявок ещё не выбран (§12 п.7). Конструктор собирает заказ
и проверяет его по правилам §8, но **деньги не списываются и заказ никуда не
уходит**. Экран успеха оставлен слово в слово по макету, а над ним стоит
полоска-предупреждение — иначе он утверждал бы, что оплата прошла.

Когда эквайринг появится: полоска удаляется одним блоком в
`src/components/gift/GiftConstructor.tsx` (помечена комментарием), а номер
заказа начинает приходить с сервера вместо клиентской генерации.

### Фильтры каталога

Состояние фильтров живёт в адресе, как требует §9 — ссылку на отфильтрованную
выдачу можно переслать:

```
/watches/?gender=f&mech=quartz      женские кварцевые
/watches/tissot/?mech=auto          Tissot на автоподзаводе
/jewelry/?type=ring&occasion=proposal   кольца под предложение
```

## Три варианта главной

Главная собрана во всех трёх вариантах сразу, переключение — без правки кода:

| Адрес | Вариант | Суть |
|---|---|---|
| `/?home=a` | Развилка | Два полноэкранных фото-блока «Часы» / «Украшения» |
| `/?home=b` | Редакционный | Крупный заголовок + CTA, ниже две карточки 4:5 |
| `/?home=c` | Витрина | Тёмный блок-манифест, ниже две полосы 3:2 с нумерацией |

Вариант по умолчанию — `variantDefault` в [`content/home.json`](content/home.json).
Всё, что ниже первого экрана, общее для трёх вариантов и не дублируется.

### Показ заказчику — `/preview`

Ссылка, которую отправляют заказчику: **`/preview/`**. Три варианта рядом,
живыми миниатюрами, с описанием каждого. Клик по карточке открывает вариант
целиком; внутри варианта снизу висит панель показа — переключение A/B/C и
кнопка «← К выбору».

Частью сайта эта страница не является. Перед релизом удаляются три вещи:
`src/app/preview/`, `src/components/preview/` и `content/preview.json` —
панель уйдёт вместе с ними.

## Как обновить контент

Весь текст сайта — в [`content/`](content), правится без пересборки логики:

| Файл | Что внутри |
|---|---|
| `site.json` | Адрес, режим работы, телефон, соцсети, пункты меню |
| `home.json` | Тексты трёх вариантов главной, блок доверия, «Почему в салоне» |
| `watches.json` | 14 марок и 14 моделей часов со всеми характеристиками |
| `jewelry.json` | 7 производителей, 8 изделий, лента Telegram |
| `brands/watches/*.md` | Статьи о 14 часовых марках |
| `brands/jewelry/*.md` | Статьи о 3 ювелирных производителях |
| `info/*.md` | Гарантия и справочник характеристик, маршруты `/info/<файл>` |
| `reference/*.md` | Таблицы официальных сайтов брендов, сводки контент-пакетов |
| `spec-hints.json` | Расшифровки характеристик — подсказки «?» в карточке товара |
| `telegram-feed.json` | Лента канала, обновляется сама раз в час (не править руками) |
| `routes.json` | Заголовки и описания страниц-заглушек |
| `preview.json` | Тексты страницы показа |

**Каталоги сейчас демонстрационные** — это структура полей из прототипа, а не
боевой ассортимент (§9 хендоффа говорит об этом прямо). Боевую выгрузку даёт
заказчик; формат полей менять не придётся.

## Структура

```
goldmean.ru/
├── InBox/          ← исходные архивы от заказчика, как пришли
├── design-ref/     ← хендофф дизайна: README, токены, кликабельный прототип
├── content/        ← контент сайта в json
├── src/
│   ├── app/        ← маршруты: (site) — сайт, preview — страница показа
│   ├── components/ ← шапка, подвал, sticky-CTA, блоки главной, показ
│   ├── lib/        ← загрузка контента, basePath, активный пункт меню
│   └── styles/     ← tokens.css, копия из design-ref
└── AGENTS.md       ← правила проекта: читать перед правками
```

## Стек

Next.js 16 (App Router, статический экспорт), React 19, Tailwind 4.
Дизайн-токены — из `design-ref/tokens.css`, проброшены в Tailwind через
`@theme inline`. Сборка отдаёт обычную статику в `out/`: её можно положить
на GitHub Pages, залить по FTP на хостинг или отдать архивом.

## Статьи о марках

Тексты пришли контент-пакетами от заказчика и лежат в `content/brands/`. Имя
файла — слаг марки; нет файла — страница собирается без статьи.

Статья стоит на том же адресе, что и каталог марки, ниже сетки моделей, с
оглавлением по разделам слева. SEO-заголовок и описание берутся из
frontmatter файла.

### Тексты написаны под существующий сайт

Это главное, что нужно знать про пакет. В статьях есть ссылки на разделы,
которых в MVP нет:

| Раздел | Упоминаний | Где |
|---|---|---|
| «Гарантия» | 15 | во всех 14 файлах часов — ✅ страница сделана |
| «Сервис» | 2 | longines |
| «Сравнить товары» | 2 | longines, tissot |
| «Оплата и доставка» | 1 | longines |
| «Возврат товара» | 1 | longines |

Тексты решено не трогать — значит, эти страницы нужно будет сделать.
«Гарантия» и «Характеристики часов» готовы, упоминания о них в статьях стали
ссылками автоматически. Остальные четыре раздела пока остаются простым
текстом.

В `garantia.md` три незакрытых вопроса к салону — на странице они подсвечены
как `[ПРОВЕРИТЬ]`: кто ставит печать в талоне, куда обращаться по гарантии,
отличается ли срок гарантии у отдельных марок.

Ювелирных статей три из семи: нет текстов для «Смоленских бриллиантов»,
«Эстета», SOKOLOV и «Бронницкого ювелира».

### Расхождения с хендоффом, согласованные с заказчиком

- **Swiss Alpine Military** — 14-я часовая марка (в §7 хендоффа их 13).
- **«Арт-Модерн»** — 7-й ювелирный производитель (в хендоффе его нет).
- **«Московский ювелирный завод» → MIUZ Diamonds** — компания сменила имя в
  2021 году. Старое название осталось в подписи под маркой.

## Что нужно от заказчика

Полный список — §12 хендоффа. Коротко:

1. Фотографии — сейчас везде плейсхолдеры с описанием нужного кадра.
2. Логотипы: девять часовых марок подключены, нужны ещё пять — Swiss Alpine
   Military, L'Duchen, Jaguar, Frederique Constant, Cover — и все семь
   ювелирных производителей. Отдельно: Raymond Weil прислан белым (версия
   для тёмного фона, перекрашен на месте), Balmain — в JPEG без прозрачности.
3. Прайс на украшения либо решение показывать «цена в салоне».
4. Дисклеймер про Meta в подвал. Аккаунт подтверждён — `zolotaya_seredina_`.
5. Канал приёма заявок: почта, Telegram-бот или CRM.
6. Срок действия подарочного сертификата.
